#Chrononutrition and risk of type 2 diabetes: a prospective cohort study

##Description
This project includes scripts used to perform the association between chrononutrition variables and the risk of type 2 diabetes. The following is a summary of each step:

##Logistic regression:
This script generates the results of the logistic regression between the chrononutrition variables and the risk of type 2 diabetes.

##Mixture:
This script generates the results of the quantile g-computation analysis that assess the association between the joint effect of chrononutrition variables and the risk of type 2 diabetes.
